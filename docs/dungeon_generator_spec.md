# ダンジョン自動生成ツール 仕様書 (dungeon_generator_spec.md)

## 1. 概要・目的

本仕様書は、TRPG やマップ探索のベースとして利用可能な **テキスト形式のダンジョン自動生成ツール** (`tools/dungeon_generator.py`) の仕様を定義します。

生成されたダンジョンマップは、グリッド（マス目）形式のテキストデータとして出力され、壁、部屋・通路、およびプレイヤーのスタート地点を視覚的な記号で表現します。

---

## 2. マップ表現記号

| 記号 | 名称 | 説明 |
| :---: | :--- | :--- |
| **`■`** | 壁 (Wall) | 通行不可能な壁・岩盤エリア |
| **`□`** | 部屋・通路 (Floor/Room) | プレイヤーやモンスターが通行可能な床エリア |
| **`◆`** | スタート地点 (Start) | プレイヤーの初期スポーン地点（最初の部屋の中心） |
| **`★`** | 最深部 / ゴール (Goal) | スタートからグラフ理論上最も遠い部屋（ボス部屋/下り階段） |

---

## 3. パラメータ仕様

コマンドライン引数 (CLI) より以下のパラメータを受け付けます。未指定の項目はランダムまたは既定値が自動適用されます。

| パラメータ名 | CLI オプション | 型 / 選択肢 | 既定値 (未指定時) | 説明 |
| :--- | :--- | :--- | :--- | :--- |
| **シード値 (Seed)** | `-s`, `--seed` | 整数 (`int`) | ランダム (`None`) | 乱数シード。同じシード値を指定することで同一ダンジョンを完全再現。 |
| **ダンジョンサイズ** | `--size` | `small`, `medium`, `large`, `xlarge` または `WxH` | `small` (20x20) | マップ全体の幅と高さ。<br>・**小 (`small`)**: 20x20マス (400セル)<br>・**中 (`medium`)**: 50x50マス (2,500セル)<br>・**大 (`large`)**: 100x100マス (10,000セル)<br>・**巨大 (`xlarge`)**: 200x200マス (40,000セル) |
| **幅・高さ個別指定** | `-w`, `--width`<br>`--height` | 整数 (`int`) | (size に準拠) | 幅と高さを個別に数値指定する場合に使用。 |
| **部屋の密度 (Density)** | `-d`, `--density` | 小数 (`0.1` 〜 `1.0`) または `low`, `medium`, `high` | ランダム (`0.25` 〜 `0.75`) | 全体に占める部屋の密集度。 |
| **ループ率 (Loop Ratio)** | `-l`, `--loop-ratio` | 小数 (`0.0` 〜 `0.5`) | ランダム (`0.10` 〜 `0.35`) | サイクロマティック数（周回路）の付加比率。<br>・`0.0`: 純木構造（完全な袋小路のみ）<br>・`0.3`: 適度な周回路と袋小路の共存 |
| **出力先ファイル** | `-o`, `--output` | ファイルパス (`str`) | 自動判定 | 生成結果を保存するテキストファイルパス。<br>※中・大・特大サイズで未指定時は安全のため自動命名保存。 |
| **プレビュー表示** | `--preview` | フラグ (`bool`) | `False` | スタート地点周辺の縮小プレビューを表示。 |
| **マップ全行出力** | `--print-all` | フラグ (`bool`) | `False` | マップ全体をコンソールに直接出力（大サイズ時は非推奨）。 |

---

## 4. ダンジョン生成アルゴリズム仕様 (数学的モデリング)

### 4.1 基本ステップ
1. **初期化**:
   - 指定されたサイズ (幅 $W$, 高さ $H$) の 2 次元グリッドをすべて **壁 (`■`)** で埋める。
2. **部屋の配置**:
   - マップサイズと密度に応じた部屋数 $|V|$ とサイズ範囲を決定し、ランダム配置。<br>部屋の最小辺は 5 マス (60 マス未満の辺では 3 マス)。60x60 未満のマップでは部屋どうしを重ねず 1 マス空ける (重ねると 1 つの大部屋に潰れるため)。
3. **グラフ理論による全連結の保証 (MST)**:
   - 全部屋の中心座標間のマンハッタン距離を算出し、**クラスカル法 (Kruskal's Algorithm)** により **最小全域木 (Minimum Spanning Tree: MST)** を構築。
   - **数学的保証**: 孤立した部屋は 0 個となり、すべての部屋の到達可能性が 100% 保証される。
4. **サイクロマティック数によるループ（周回路）付加**:
   - MST で採用されなかった余分な辺から、指定されたループ率 $p_{\text{loop}}$ に応じて辺を追加。
   - 独立閉路数（サイクロマティック数 $M = |E| - |V| + 1$）を制御。
5. **通路の掘削と袋小路の付加**:
   - 決定されたエッジ集合 $E$ に従い、L字型マンハッタン配線で通路を床 (`□`) として掘削。
   - 分岐点からランダムな行き止まり路（袋小路）を追加掘削。
6. **最遠点探索によるスタート (◆) とゴール (★) の自動決定**:
   - 最初の部屋に **スタート地点 (`◆`)** を配置。
   - グラフ上で幅優先探索 (BFS) を行い、**スタート地点から最短経路長が最も遠い部屋**を数学的に選出して **ゴール・最深部 (`★`)** とする。
7. **外周の壁封鎖 (Outer Wall Constraint)**:
   - 外周4辺（$y=0, y=H-1, x=0, x=W-1$）の全マスを **必ず壁 (`■`)** で再封鎖し、密閉空間を保証。

## 5. CLI 使用例

### 5.1 基本実行 (サイズ小: 20x20、シード・密度ランダム)
```bash
python3 tools/dungeon_generator.py
```

### 5.2 シード値と密度を指定してファイルに保存
```bash
python3 tools/dungeon_generator.py --seed 42 --density high -o dungeon_output.txt
```

### 5.3 縮小プレビュー付きで実行
```bash
python3 tools/dungeon_generator.py --size small --preview
```
